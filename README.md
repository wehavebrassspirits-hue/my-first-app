# 🍚 週間こんだてメーカー

次の週の天気予報に合わせて、1週間分の晩ごはんを自動で提案してくれるアプリです。
サーバー不要・ブラウザだけで動きます（HTML / CSS / バニラJS）。

## 特長

- 🌦️ **天気連動**：次の週（翌週の月〜日）の予報を取得し、
  - 寒い日 → 鍋・シチュー・煮込み
  - 暑い日 → 冷やし麺・さっぱり系
  - 雨/雪の日 → 手間少なめ・温かい家メシ
  を自動で選びます。
- 👨‍👩‍👧‍👦 **家族構成に対応**：人数・アレルギー・苦手食材を設定でき、
  「育ち盛り・運動する子向けにスタミナ多め」も切り替え可能。
- 🎲 **別案・個別変更**：週まるごと／1日だけの入れ替えができます。
- 🛒 **買い物リスト**：1週間分の材料を自動でまとめて表示します。
- 💾 設定は**その端末のブラウザ内（localStorage）だけ**に保存されます。

初回起動時に設定画面が開くので、地域・人数・アレルギー・苦手食材を入力してください。
右上の「設定 ⚙️」からいつでも変更できます。

## プライバシー

- 家族構成などの入力内容は**利用者の端末の中だけ**に保存され、サーバーには送信しません
  （このアプリにはサーバーもアカウントもありません）。
- 天気の取得時のみ、選択した地域のおおよその緯度経度が Open-Meteo に送られます。
- そのため、ソースコードや公開ページに個人情報は一切含まれません。

## 使い方

### いちばん簡単な方法
`index.html` をブラウザで開くだけです（ダブルクリック）。

### うまく天気が取得できないとき
一部のブラウザは `file://` から外部APIを呼べないことがあります。
その場合は簡易サーバー経由で開いてください：

```bash
# このフォルダで実行
python3 -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

## 天気データについて

[Open-Meteo](https://open-meteo.com/) の無料予報APIを使用しています
（APIキー不要）。地域は設定画面のプルダウンから選べます
（宇都宮・東京・大阪・名古屋・福岡・札幌・仙台・広島）。

## ファイル構成

```
index.html      画面
css/style.css   デザイン
js/meals.js     献立データベース（気温帯・雨向き・スタミナ度などのタグ付き）
js/weather.js   天気取得（Open-Meteo）と気温帯の判定
js/app.js       献立の選定ロジック・描画・設定・買い物リスト
```

## カスタマイズ

献立を増やしたいときは `js/meals.js` の `MENUS` に追記してください。
1件あたりのタグの意味はファイル冒頭のコメントに記載しています。
